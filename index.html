Bem-vindo ao NEXO

        
Um desafio de raciocínio lógico com palavras e diagramas de Venn.

        
Duas regras, quatro regiões. Classifique cada palavra no lugar certo.

      


      

        
Como jogar

        
Arraste (ou toque) cada palavra para a região correta:

        
    
          
  • Só A — cumpre apenas a regra A
    • 
          
  • Só B — cumpre apenas a regra B
    • 
          
  • Interseção — cumpre as duas
    • 
          
  • Nenhuma — não cumpre nenhuma
    • 
        

        
Use 💡 Dicas quando travar. Cada dica custa 5 pontos.

      


      

        
Três modos de jogo

        
    
          
  • Clássico — infinito, dificuldade crescente
    • 
          
  • 📅 Diário — mesmo puzzle para todos, todo dia. Mantenha seu streak!
    • 
          
  • 🔥 Hardcore semanal — 3 regras, 8 regiões, adivinhe a palavra central
